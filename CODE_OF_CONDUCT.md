# Code of Conduct

This project is dedicated to maintaining a welcoming and respectful community.

## Our Standards

- Be respectful and professional.
- Assume good intent in others.
- Communicate clearly and constructively.
- Do not tolerate harassment or abusive language.

## Reporting Issues

If you observe unacceptable behavior, please report it through the repository issue tracker or contact the maintainers.

## Enforcement

Project maintainers may remove comments, close issues, or block contributors for behavior that violates this code of conduct.
