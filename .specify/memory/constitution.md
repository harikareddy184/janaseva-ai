# JanSeva AI Constitution

## Purpose
JanSeva AI is an AI-powered civic assistant helping Indian citizens access government services and civic support.

## Tech Stack
- Python
- Streamlit
- Groq LLM API
- SQLite database
- REST APIs

## Development Rules
- Keep code modular and readable
- Use environment variables for API keys
- Never expose secrets
- Maintain proper folder structure
- Add comments for important logic

## UI Guidelines
- Simple citizen-friendly interface
- Mobile-friendly design
- Clear responses

## Testing
- Test every feature before deployment
- Fix errors before merging

## Deployment
Application should run using Streamlit.
