# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository, please report it by opening a private issue if the hosted platform supports it, or by using the project contact channel.

Do not publish security issues publicly until they have been fixed.

## What to Include

- Description of the issue
- Steps to reproduce
- Affected version or commit
- Any code or configuration details that demonstrate the problem

## Responsible Disclosure

We aim to respond to all security reports promptly. Please allow a reasonable time for maintainers to investigate and fix reported vulnerabilities.
